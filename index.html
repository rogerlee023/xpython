❓ 常见问题（Q/A）

Q：下载/安装时 Windows 弹出蓝色 SmartScreen 警告，怎么办？ ▼

原因：XPython 目前处于初期推广阶段，尚未购买商业代码签名证书。Windows SmartScreen 对未签名的、下载量较少的程序会默认保持谨慎，这是正常的保护机制，不代表文件含有病毒[citation:8]。

操作步骤：

  1. 在蓝色提示窗口中点击 “更多信息”；
  2. 确认展开后点击 “仍要运行”；
  3. 安装即可正常进行。

你可以在本地用 PowerShell 运行 Get-FileHash 文件名.exe，与 Release Notes 中公布的 SHA-256 值比对，进一步确认文件完整性。

Q：360 安全卫士把安装包报为病毒并移入隔离区，如何处理？ ▼

原因：360 的启发式引擎对无数字签名、下载量较少的新程序较为敏感，容易出现误报。开发者已向 360 提交误报申诉，审核通过后病毒库更新即可消除。

临时操作步骤：

  1. 打开 360 安全卫士 → 「查杀修复」；
  2. 点击右下角 「恢复区」，找到 XPython 安装包，点击 「恢复」[citation:5]；
  3. 进入 「设置」→「病毒查杀设置」→「信任区」，将安装包添加为信任文件[citation:5]。

如果恢复后仍然被拦截，可以暂时关闭 360 的实时防护完成安装，安装后重新开启。建议优先等待 360 官方病毒库更新。

Q：为什么 XPython 没有软件签名？以后会有吗？ ▼

代码签名证书的年费成本较高（正规 OV 证书约 $150–300/年），且即使购买签名，SmartScreen 信誉仍需数周至数百次干净安装才能积累起来，并不能立即消除警告[citation:8]。现阶段我们将成本集中在功能开发上，待用户规模稳定后会评估签名方案。在此之前，我们通过公布文件哈希、提供 VirusTotal 自查链接等方式，让用户可以自行验证文件安全。

Q：安装或运行时出现 Windows 蓝屏（BSOD）怎么办？ ▼

蓝屏通常由驱动冲突、系统文件损坏或硬件问题引起，与单一应用程序的直接关联较少见。建议按以下顺序排查：

  1. 重启电脑，观察是否复现；
  2. 进入 设备管理器，检查是否有带黄色感叹号的设备，更新显卡/芯片组驱动；
  3. 以管理员身份运行命令提示符，执行 sfc /scannow 修复系统文件；
  4. 如果蓝屏仅在运行 XPython 时出现，请通过邮箱联系我们，并提供蓝屏错误代码（如 0x0000003B 等）和系统版本信息。

如果蓝屏频繁出现且与 XPython 无关，建议使用 Windows 内存诊断工具（搜索“Windows 内存诊断”）检查 RAM 是否有问题。
